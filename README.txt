STEM WITHOUT BARRIERS — EDITABLE WEBSITE

Extract the ZIP, keeping all files and the assets folder together.
Open index.html in a browser. No installation or build step is needed.

FILES
index.html — semantic HTML, with EN / FI / SV sections and editable text.
styles.css — layout, colours, typography and responsive styles.
script.js — language switching and remembered language preference.
assets/ — three transparent PNG logos.

EDITING
Edit text in the relevant language section of index.html.
The monthly schedule is in each section with id sessions-en / fi / sv.
The form action is https://formspree.io/f/xeajgzbr in each form.
Form submission requires internet access. No test submission was sent.
Upload all files together when publishing; do not upload only index.html.
The website is not published by creating this archive.
